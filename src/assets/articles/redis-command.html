Redis Commands

Redis is a blazing-fast in-memory database used for caching, messaging, and real-time data processing. This cheat sheet covers the most essential Redis commands so you can boost your app’s performance and scale with ease.

1. Strings (Basic Key-Value)

  • SET key value — Set key to hold string value
  • GET key — Get value of key
  • DEL key — Delete key
  • EXPIRE key seconds — Set TTL for key
  • TTL key — Check remaining TTL
  • INCR key — Increment integer value by 1
  • APPEND key value — Append to existing string

2. Lists (Ordered Collections)

  • LPUSH key value — Push value to the start
  • RPUSH key value — Push value to the end
  • LRANGE key start stop — Get elements from index
  • LPOP key — Remove and get first element
  • RPOP key — Remove and get last element
  • LLEN key — Get length of list
  • LREM key count value — Remove occurrences of value

7. RedisJSON (if module installed)

  • JSON.SET key path json — Set JSON value
  • JSON.GET key [path] — Get JSON value
  • JSON.DEL key [path] — Delete JSON path
  • JSON.MGET key [path] — Get JSON values
  • JSON.TYPE key [path] — Get JSON type

Bonus: Transactions & Atomicity

  • MULTI — Start transaction
  • EXEC — Execute transaction
  • DISCARD — Cancel transaction
  • WATCH key — Watch key for changes
Redis is simple once you know your data types and matching commands. Master these and you can build almost anything.
